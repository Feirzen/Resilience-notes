# Notice: what is NoteMaker's, and what isn't

**NoteMaker** (the code, screens, design, and documentation in this repository) was created independently by S. Wills, on personal time and personal equipment.

## Not part of NoteMaker
NoteMaker is built to fit an existing workflow, so it reproduces the layout of materials that belong to Resilience Health. These are **Resilience Health's property**, not part of NoteMaker's own product, and are copied only so the output matches what the team already uses:

- The progress note and H&P (adult and adolescent) templates and their wording
- The provider patient sheet (census spreadsheet) layout
- Unit, site, and provider names

## Patient information
This repository contains no patient information. Demo mode uses made-up patients only (`lib/demo.js`).

## Planned, not built
These are intentions only. None of them exist in the code yet:

- Microsoft (Entra ID) sign-in
- A direct SharePoint connection
- Hosting on hospital servers

Third-party libraries in `vendor/` keep their own open-source licenses.
